# 🛒 E-Commerce Sales Analytics Dashboard

## 📌 Overview
This project focuses on analyzing e-commerce order data using SQL and building an interactive dashboard using Streamlit. The goal is to extract meaningful business insights such as revenue trends and customer behavior.

---

## 🎯 Objectives
- Analyze sales performance using SQL queries  
- Identify top customers and revenue trends  
- Build a dashboard for real-time data visualization  
- Demonstrate end-to-end data analytics workflow  

---

## ⚙️ Tech Stack
- SQL (MySQL)  
- Python (Pandas)  
- Streamlit  
- Git & GitHub  

---

## 📊 Key Features
- 📈 Monthly revenue trend analysis  
- 🏆 Top customer identification  
- 📦 Total orders and KPI tracking  
- 💰 Average order value calculation  
- 🔍 Interactive dashboard using Streamlit  

---

## 🧠 SQL Concepts Used
- SELECT, WHERE, GROUP BY  
- Aggregations (SUM, AVG, COUNT)  
- Sorting and filtering  
- Basic data analysis queries
